# Home Credit LAP AI Voice Agent

## Overview

An AI voice agent built using Bolna Agent Studio for preliminary qualification of existing Home Credit customers for a Loan Against Property (LAP) offer of up to ₹75,00,000.

## Objective

The agent informs customers about the LAP offer and performs a preliminary eligibility check before handing qualified customers to a senior loan expert.

## Key Features

- Customer identity verification
- Busy customer and callback handling
- Loan Against Property offer explanation
- Residential, commercial, and industrial property eligibility
- Sole and joint ownership support
- Original property document verification
- Loan amount validation up to ₹75,00,000
- Salaried and self-employed customer handling
- Bank-based income verification
- Property market value collection
- 3–15 year tenure validation
- Existing loan / EMI reduction transfer handling
- Out-of-order information handling
- Final preliminary qualification
- Senior loan expert handoff
- Immediate call termination after closing

## Technology

- Bolna Agent Studio
- AI Voice Agent
- Web Call
- Prompt-based conversational workflow

## Testing

The agent was tested using Bolna Web Call with an eligible customer scenario. The test covered all seven preliminary eligibility criteria and successfully completed the qualification and handoff flow.

## Important Note

This project uses a no-code voice-agent implementation through Bolna Agent Studio. The repository contains project documentation and configuration information; the voice agent itself is configured and executed on the Bolna platform.
